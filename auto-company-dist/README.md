# Auto Company Distribution Package

Complete deployment package for Auto Company products and landing page.

## Quick Start

1. **Authenticate** (required, 2 minutes):
```bash
npm login
vercel login
gh auth login
```

2. **Deploy everything**:
```bash
./scripts/deploy-all.sh
```

## What's Included

- **4 Products:** env-diff, gh-analytics, keyspinner-scan, reviewflow-cli
- **Landing Page:** Next.js production build
- **Deploy Script:** One-command deployment
