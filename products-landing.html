url-to-md

Convert any webpage to clean markdown

Strip ads, sidebars, comments, and popups. Extract the main content and save as clean markdown.

  • Zero cloud, zero tracking
  • Saves locally to your machine
  • Perfect for offline reading
$npm install -g @eylulsenakumral/url-to-md
📝

local-notes

Terminal-based note-taking. Zero cloud.

Fast, local note-taking from your terminal. Notes stored as plain Markdown files with frontmatter.

  • Create, search, view, delete notes
  • Tag support for organization
  • Your data stays on your machine
$npm install -g local-notes-cli
🔍

ai-slop-detector

Detect AI-generated code slop

Heuristic-based CLI tool to detect AI-generated code patterns. No AI required — just statistics.

  • 9 detection heuristics
  • JSON output for CI/CD
  • Works on JavaScript, TypeScript, Python
$npm install -g ai-slop-detector

🚀 Install Locally (No npm publish required)

Can't wait for npm publish? Install directly from source:

Requires: Node.js + npm

url-to-md:

$cd ~/projects/Auto-Company/projects/url-to-md && npm link

local-notes:

$cd ~/projects/Auto-Company/projects/local-notes && npm link

ai-slop-detector:

$cd ~/projects/Auto-Company/projects/ai-slop-detector && npm link

Note: Projects are located in ~/projects/Auto-Company/projects/ on the development machine.

📚 Quick Start

url-to-md

$url2md https://example.com/article
$url2md https://example.com --output=my-article.md

local-notes

$ln add "meeting notes"
$ln add "quick idea" -c "content here"
$ln list

ai-slop-detector

$slop src/app.js
$slop . --threshold 30
$slop src/ --json
