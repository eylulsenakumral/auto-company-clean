Convert any webpage to clean markdown. Strip ads, bloat, clutter.

## Installation

### Option 1: Direct from GitHub (Recommended, No Token Required)

```bash
# Clone the repo
git clone https://github.com/eylulsenakumral/auto-company.git
cd auto-company/projects/url-to-md

# Install globally
npm install -g .
```

### Option 2: npm (When Published)

```bash
npm install -g @eylulsenakumral/url-to-md
```

## Usage

```bash
url2md https://example.com/article
url2md https://example.com --output=my-article.md
```

## What it does

- Removes ads, sidebars, comments, popups
- Extracts main content only
- Converts to clean markdown
- Saves locally — no cloud, no tracking

## Use cases

- Save articles for offline reading
- Strip bloat from recipe sites
- Clean up blog posts before sharing
- Archive web content in git
