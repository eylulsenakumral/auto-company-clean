## Quick Checklist

After completing this guide, you should have:

- [ ] GitHub CLI authenticated (`gh` commands work)
- [ ] Vercel CLI authenticated (`vercel` commands work)
- [ ] npm configured for publishing
- [ ] GitHub repo secrets configured (if using Actions)

---

## Option 1: GitHub Auth (Recommended)

**Why:** Unblocks resume-analyzer + enables gh commands for all projects

```bash
# Authenticate with GitHub
gh auth login

# Select: GitHub.com
# Select: SSH (preferred) or HTTPS
# Select: Login with a browser OR Paste an authentication token
```

**Verify:**
```bash
gh auth status
```

---

## Option 2: Vercel Auth

**Why:** Unblocks resume-analyzer deployment

```bash
# Install Vercel CLI (if not installed)
npm install -g vercel

# Login
vercel login

# Follow browser prompts
```

**Verify:**
```bash
vercel whoami
```

---

## Option 3: npm Auth

**Why:** Unblocks reviewflow-cli publishing

```bash
# Create npm token
npm token create

# Add to ~/.npmrc
echo "//registry.npmjs.org/:_authToken***REMOVED***<YOUR_TOKEN>" >> ~/.npmrc

# Verify
npm whoami
```

## GitHub Actions Secrets (Optional)

If using CI/CD workflows, configure repo secrets:

```bash
# For each repo
gh secret set VERCEL_TOKEN --body <your-vercel-token>
gh secret set NPM_TOKEN --body <your-npm-token>
```
